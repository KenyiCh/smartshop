# SmartShop

Comparador de precios con wishlist, alertas de precio, reseñas y panel de administración.

Base inicial migrada desde el prototipo de Lovable (`smartshop-price-pilot-42`).

## Stack
- React + Vite + TypeScript
- Tailwind CSS + shadcn/ui

## Estado actual
- Front-end completo con datos de prueba (mock).
- Sesión guardada en `localStorage` (sin backend aún).

## Cómo correrlo
```sh
npm i
npm run dev
```
